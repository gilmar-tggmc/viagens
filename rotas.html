1. Base de municípios e exportação

O cadastro de municípios usa o mesmo critério e a mesma fonte do explorador original. O status inicial de todas as modalidades é pendente. Um município poderá ter várias rotas para o mesmo meio de deslocamento.

Dados locais: as rotas preenchidas ficam somente neste navegador e neste dispositivo. O site não tem banco de dados ou sincronização. Exporte o backup JSON após cada sessão de trabalho para não perder informações. O CSV exporta a matriz inteira para conferir no Excel.

4. Regras do levantamento

O projeto começa com Paulo Afonso, mas os arquivos são preparados para aceitar outras origens no futuro. Para cada destino, o painel cria quatro oportunidades de pesquisa: carro, moto, bicicleta e caminhada. Percursos alternativos são cadastrados separadamente, podendo ter extensão e pavimentação distintas.

Classificação: 100% asfalto, 100% chão, híbrido, outro pavimento e superfície desconhecida são definidos a partir dos quilômetros cadastrados. Se qualquer trecho for desconhecido, o tipo de superfície será sinalizado como parcialmente desconhecido.

Fonte de coordenadas: Municípios Brasileiros (kelvins). Tipo de piso: consultar os atributos surface=* do OpenStreetMap e, quando necessário, verificar em imagens e fontes locais. Roteamento futuro: motores separados por modalidade; o percurso de carro não será simplesmente copiado para moto, bicicleta e caminhada.

Não é um GPS: esta versão organiza pesquisas e registros. Ela ainda não calcula rotas reais automaticamente, não verifica permissões de tráfego, não distingue trechos asfaltados por reconhecimento remoto, nem contém horários ou valores de transporte coletivo.
